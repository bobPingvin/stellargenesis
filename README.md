## 🌟 О проекте

**StellarGenesis** — это высокопроизводительное научно-образовательное веб-приложение для моделирования и исследования астрофизических процессов реального времени в браузере с постоянной частотой **60 FPS**:
- Численное решение гравитационной задачи $N$-тел с симплектическим интегратором **Velocity Verlet**;
- Моделирование термоядерного нуклеосинтеза и гидростатического равновесия звезд;
- Звездные катастрофы: планетарные туманности, сверхновые типа II, гиперновые и рождение компактных остатков (белых карликов, миллисекундных пульсаров, черных дыр);
- Релятивистские эффекты ОТО и СТО: гравитационное линзирование Эйнштейна на GPU (GLSL-шейдеры), эффект Доплера (синее/красное смещение), релятивистский биминг и приливная спагеттификация (TDE).

## ✨ Ключевые возможности

- 🪐 **Гравитационный N-body движок:** Сохранение энергии и импульса системы, гравитационное смягчение Пламмера ($\varepsilon = 8.0$), релятивистское ограничение скорости $v \le c$.
- 💥 **Звездная эволюция и нуклеосинтез:** Термоядерные циклы $\text{H} \to \text{He} \to \text{C} \to \text{Fe}$, баланс $P_{\text{grav}} \leftrightarrow P_{\text{gas}} + P_{\text{rad}}$, эволюционные пределы Чандрасекара ($1.44\,M_\odot$) и Оппенгеймера-Волкова ($2.8\,M_\odot$).
- 🕳️ **3D WebGL инспектор сингулярностей (`Celestial3DViewer`):** Процедурный raymarching-шейдер гравитационного линзирования света звездного фона в метрике Шварцшильда, кольца Эйнштейна, аккреционные диски и джеты.
- 🔴 **Релятивистский эффект Доплера и биминг:** Вычисление продольного сдвига спектра $z = \sqrt{\frac{1-\beta}{1+\beta}} - 1$, трансформация цвета и усиление светимости приближающихся тел.
- 🍝 **Приливная спагеттификация (Tidal Disruption Event):** Расчет предела Роша, приливное растяжение в эллипсоид, стриппинг массы и рождение спиральных светящихся плазменных нитей.
- 🌌 **Каталог готовых астрофизических пресетов:** «Солнечная система», «Пульсар Краба», «Тесная двойная звездная система», «Сверхмассивная черная дыра».
- ⏱️ **Управление временем и историей:** Изменение масштаба времени ($0.1\times - 5.0\times$), пауза, глубокие снимки состояния и Undo/Redo (`Ctrl+Z` / `Ctrl+Y`).
- 🔊 **Процедурный синтезатор звука (Web Audio API):** Звуковой ландшафт космоса: радиоимпульсы пульсаров, басовый гул сингулярностей, взрывные волны сверхновых.
- 📱 **Адаптивный интерфейс:** Поддержка мобильных устройств (320px+), нижняя панель быстрого доступа `QuickDock`, сворачиваемый инспектор характеристик.

## 🚀 Быстрый старт

### Требования
- **Node.js:** версия `18+` или `20+` LTS
- **Браузер:** Google Chrome, Firefox, Safari или Edge с поддержкой WebGL 2.0

### Установка и локальный запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/bobPingvin/stellargenesis.git
cd stellargenesis

# 2. Установка npm-зависимостей
npm install

# 3. Запуск dev-сервера (по умолчанию порт 3000)
npm run dev
```

Откройте в браузере адрес: **`http://localhost:3000`**

### Сборка и тестирование

```bash
# Запуск автоматизированных тестов Vitest (38 unit-тестов)
npm test

# Сбор инструментального отчета о покрытии кода тестами
npm run test:coverage

# Валидация статических типов TypeScript
npm run lint

# Сборка продакшн-бандла
npm run build
```
