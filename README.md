## 🌟 О проекте

**StellarGenesis** — это высокопроизводительный научно-образовательный симулятор астрофизических процессов реального времени, объединяющий численное моделирование гравитационной задачи $N$-тел, квантово-релятивистскую звездную термодинамику и визуализацию искажения пространства-времени Общей теории относительности (ОТО) на GPU с помощью GLSL-шейдеров.

Проект разработан для демонстрации астрофизических законов, исследования динамики орбит, столкновений массивных тел, образования аккреционных дисков и наблюдения черных дыр в браузере с постоянной частотой **60 FPS**.

## ✨ Ключевые возможности

### 🕳️ Релятивистское гравитационное линзирование (GPU WebGL2)
- **Screen-Space Raymarching Шейдер**: Моделирование искривления лучей света звездного фона в метрике Шварцшильда.
- **Фотонные кольца и сфера Эйнштейна**: Формирование первичных и вторичных оптических изображений вокруг горизонта событий черной дыры.
- **Вращающиеся черные дыры**: Искривление диска аккреции в стиле сверхмассивной черной дыры *Гаргантюа*.

### 💥 Звездная эволюция и нуклеосинтез
- **Гидростатическое равновесие**: Баланс между гравитационным сжатием и радиационным давлением термоядерного синтеза.
- **Циклы выгорания элементов**: Поэтапное сгорание $\text{H} \rightarrow \text{He} \rightarrow \text{C} \rightarrow \text{O} \rightarrow \text{Si} \rightarrow \text{Fe}$.
- **Предел Чандрасекара ($1.44\,M_\odot$)**: Сброс оболочки и образование белых карликов для звезд промежуточной массы.
- **Предел Оппенгеймера-Волкова ($3.0\,M_\odot$)**: Гравитационный коллапс в пульсар / нейтронную звезду или черную дыру звездной массы.
- **Сверхновые и гиперновые**: Эмиссия релятивистской ударной волны, разлет обогащенной туманности и мощные световые вспышки.

### 🔴 Релятивистский эффект Доплера & Beaming
- Спектральное смещение излучения тел и частиц материи в зависимости от проекции их вектора скорости на луч зрения наблюдателя:
  - 🔵 **Синее смещение (Blueshift)** — при приближении объекта к наблюдателю.
  - 🔴 **Красное смещение (Redshift)** — при удалении объекта.

### 🍝 Приливная спагеттификация (Tidal Disruption)
- Неоднородное гравитационное поле разрывает сближающиеся планеты и газовые облака в тонкие светящиеся филаменты, закручивающиеся в спиральные аккреционные рукава.

### 🌐 Ткань пространства-времени
- Динамическая деформируемая координатная сетка, наглядно отображающая потенциальные гравитационные ямы и искривление пространства массивными объектами.

### 🎵 Процедурный акустический движок (Web Audio API)
- Синтез низкочастотного басового гула искривления пространства, звуков слияний черных дыр (Chirp signal) и ударных акустических волн сверхновых.

## 🔬 Физические и математические модели

| Модель / Закон | Математическое описание | Реализация в симуляторе |
| :--- | :--- | :--- |
| **Гравитация $N$-тел** | $\vec{F}_{ij} = G \frac{m_i m_j}{(r^2 + \varepsilon^2)^{3/2}} \vec{r}_{ij}$ | Интегратор Верле со смягчением Пламмера $\varepsilon$ |
| **Радиус Шварцшильда** | $R_s = \frac{2GM}{c^2}$ | Вычисление горизонта событий и предела поглощения |
| **Фотонная сфера** | $R_{ph} = 1.5\,R_s$ | Предел нестабильных круговых орбит фотонов |
| **Кольцо Эйнштейна** | $\theta_E = \sqrt{\frac{4GM}{c^2} \frac{D_{LS}}{D_L D_S}}$ | Угловой радиус оптического преломления в WebGL |
| **Спагеттификация** | $\frac{dF}{dr} = -2G \frac{M m}{r^3}$ | Расчет тензора приливных сил растяжения частиц |
| **Эволюционные пределы** | $M_{Ch} \approx 1.44\,M_\odot, \quad M_{TOV} \approx 3.0\,M_\odot$ | Автоматическая классификация реликтов ядра |

## 🌌 Встроенные астрофизические сценарии

В боковом меню доступны готовые сценарии для моментального запуска:
1. ☀️ **Солнечная система** — звезда главной последовательности и планеты на устойчивых кеплеровых орбитах.
2. 🕳️ **Танец черных дыр (Binary Black Hole)** — двойная релятивистская система с взаимным линзированием и аккреционными дисками.
3. 🌀 **Спиральная галактика** — сверхмассивная черная дыра в центре и сотни звезд с распределением скоростей кривой вращения.
4. 💥 **Коллапс скопления (Cluster Collapse)** — хаотическое столкновение протозвезд с серией взрывов сверхновых.
5. 🪐 **Приливный разрыв (Tidal Disruption Event)** — захват и спагеттификация планеты при пролете около горизонта событий.

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- Современный браузер с аппаратным ускорением (Chrome, Firefox, Safari, Edge)

### Установка и запуск

```bash

npm run build
```

## ⚡ Оптимизация производительности

Для стабильной работы симулятора даже на мобильных устройствах и интегрированных видеокартах применены передовые техники оптимизации:
- **Batched Particle Rendering**: Отрисовка сотен частиц сгруппированными вызовами по цветовым палитрам за один проход `ctx.fill()`.
- **Frustum Culling**: Мгновенное отсечение небесных тел, векторов и шлейфов, находящихся за границами видимой области экрана.
- **LOD Пресеты Графики**:
  - `60+ FPS (Быстро)`: Отключение экранного шейдера, лимит до 350 частиц.
  - `Баланс (Стандарт)`: Включенный WebGL-шейдер гравилинз, лимит 800 частиц.
  - `Ультра (Эффекты)`: Полный спектр релятивистских эффектов, до 1500 частиц.
