## Слайд 2. Проблема и актуальность
- **Выявленные проблемы:**
  - *Абстрактность теории:* Уравнения ОТО, метрика Шварцшильда и циклы нуклеосинтеза сложны для восприятия по статичным схемам в учебниках.
  - *Дефицит интерактивных сред:* Существующие научные астрофизические пакеты (REBOUND, GalSim) требуют сложной настройки окружения Python/C++ и не дают наглядного интерактива.
  - *Медленная визуализация:* Большинство веб-демографий ограничены упрощенным законом Ньютона без релятивизма и гравитационных линз.
- **Предлагаемое решение (StellarGenesis):**
  - Доступность в один клик прямо в веб-браузере без установки стороннего ПО (320px+ до 4K).
  - Высокая производительность: интегратор Верле и GPU-шейдеры WebGL 2.0 обеспечивают стабильные 60 FPS.
  - Научная строгость: реализованы реальные физические пределы Чандрасекара, Оппенгеймера-Волкова, предел Роша и эффект Доплера.

## Слайд 3. Цель и задачи проекта
- **Главная цель:** Разработка высокопроизводительного отечественного программного комплекса для интерактивного моделирования N-body гравитации, звездной эволюции и релятивистских явлений в веб-среде с открытым исходным кодом.
- **Ключевые задачи:**
  1. *Математическое ядро:* Реализация симплектического N-body интегратора Верле со смягчением Пламмера и законами сохранения импульса.
  2. *Звездная эволюция:* Моделирование термоядерных циклов $\text{H} \to \text{Fe}$, гидростатического баланса, взрывов сверхновых и коллапса в черные дыры.
  3. *3D WebGL и релятивизм:* Разработка процедурного raymarching-шейдера гравилинзирования Эйнштейна, формул эффекта Доплера и спагеттификации TDE.
  4. *Качество и надежность:* Внедрение тестового контура Vitest (38 тестов, 100% PASS), аудит качества кода по ISO/IEC 25010, разработка полного комплекта документации.

## Слайд 5. Функциональность релизной версии v1.0
- **Симплектический N-body интегратор:** Алгоритм Velocity Verlet со смягчением Пламмера ($\varepsilon=8.0$), строгим сохранением энергии/импульса и релятивистским лимитом $v \le c$.
- **Звездный нуклеосинтез и термодинамика:** Баланс $P_{\text{grav}} \leftrightarrow P_{\text{gas}} + P_{\text{rad}}$, сгорание $\text{H} \to \text{He} \to \text{C} \to \text{Fe}$, расширение в красный гигант.
- **Ветвления звездных катастроф:** Планетарные туманности и белые карлики ($< 1.44\,M_\odot$), вспышки Сверхновых II типа и пульсары ($8-20\,M_\odot$), гиперновые и сингулярности ($> 2.8\,M_\odot$).
- **Приливная спагеттификация (TDE):** Расчет предела Роша, приливный эллипсоид, стриппинг массы (85% аккреция) и процедурные плазменные струи.
- **Релятивистский эффект Доплера & Beaming:** Спектральный сдвиг $z = \sqrt{\frac{1-\beta}{1+\beta}}-1$: синее смещение приближения, красное смещение удаления.
- **3D WebGL инспектор сингулярностей:** Raymarching шейдер линзирования Эйнштейна, фотонные сферы и диски аккреции.

## Слайд 6. Демонстрация работы системы
- **Интерактивное полотно Canvas 2D (60 FPS):** Отрисовка небесных тел, динамических трейлов и деформируемой сетки пространства-времени.
- **Верхняя панель навигации (TopNavigation):** Каталог сценариев (Солнечная система, Пульсар, Черная дыра), кнопка звука Web Audio.
- **Нижний док быстрого доступа (QuickDock):** Пауза/старт, слайдер масштаба времени ($0.1\times - 5.0\times$), тумблеры трейлов и спавна.
- **Боковой инспектор (StarInspector):** Карточка характеристик: масса, радиус, температура, светимость, круговая диаграмма нуклеосинтеза, кнопка 3D-обзора.
- **Адаптивность:** Поддержка мобильных экранов от 320px и управление тач-жестами (Pinch-to-zoom).

## Слайд 7. Архитектура системы и стек технологий
- **UI & State Management:** React 19.0.1 + TypeScript 5.8 (компонентная модель, хуки, строгая статическая типизация).
- **Стилизация и интерфейс:** Tailwind CSS v4.3 + Lucide React Icons (адаптивная тёмная тема).
- **2D Canvas Viewport:** HTML5 Canvas API (батчинг отрисовки частиц, буферизация трейлов орбит).
- **3D WebGL Engine:** Three.js + WebGL 2.0 GLSL Shaders (процедурный raymarching черных дыр).
- **Звуковой движок:** Web Audio API (процедурный синтез радиоимпульсов пульсаров и басового гула ОТО).
- **Тестирование и сборка:** Vitest 5.0 (@vitest/coverage-v8) + Vite 8.3 (быстрая сборка, 38 тестов).
