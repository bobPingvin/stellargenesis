## 3. Функции, вынесенные за рамки Unit-тестирования (Out of Unit Scope)

Следующие модули намеренно тестируются через ручное сценарное тестирование (Дни 8–9) и E2E-проверки ввиду жесткой привязки к браузерному GPU/Audio контексту:

1. **`renderCanvas` (`src/components/CanvasViewport.tsx`):**
   - *Причина:* Прямой рендеринг в контекст HTML5 Canvas 2D (`CanvasRenderingContext2D`) требует мока графического пайплайна браузера и проверяется визуально на отсутствие артефактов и частоту кадров (60 FPS).
2. **`Celestial3DViewer` / Shaders (`src/physics/blackHole3DRenderer.ts`, `src/physics/pulsar3DRenderer.ts`):**
   - *Причина:* Процедурные шейдеры GLSL линзирования Эйнштейна и трехмерные сцены Three.js компилируются на стороне видеокарты (WebGL 2.0).
3. **`SoundSynthesizer` (`src/physics/audio.ts`):**
   - *Причина:* Web Audio API требует аппаратно-поддерживаемого `AudioContext` и пользовательского жеста (User Gesture Policy).
