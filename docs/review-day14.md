## 2. Конкретные замечания и рекомендации по результатам ревью

### Комментарий 1: Отсутствие описания обработки сбоев сети в Руководстве пользователя
- **Категория:** Пользовательская документация (`docs/user-guide.md`)
- **Суть замечания:**
  В разделе 3 («Основные функции») подробно описан позитивный сценарий («Happy Path») оформления бронирования и подтверждения слота. Однако полностью отсутствует описание поведения системы и действий пользователя при сбое сохранения данных в LocalStorage (например, при переполнении квоты хранилища или работе в приватном режиме браузера).
- **Рекомендация:**
  Добавить в подраздел 3.3 или в раздел «Часто задаваемые вопросы» (FAQ) инструкцию: что делать пользователю, если кнопка «Забронировать» выдает предупреждение об ошибке сохранения, и как восстановить несохраненный заказ.

---

### Комментарий 2: Неполный раздел Troubleshooting в Руководстве по установке
- **Категория:** Руководство по установке (`docs/install-guide.md`)
- **Суть замечания:**
  В разделе «Решение проблем» приведена только одна типовая ошибка — конфликт порта. При этом не описаны частые проблемы развертывания:
  1. Несовместимость версий Node.js (при запуске на устаревших версиях Node < 18, где недоступен глобальный объект `structuredClone` или нативный `fetch`);
  2. Ошибки сборки Vite при установке зависимостей с ключом `--legacy-peer-deps`.
- **Рекомендация:**
  Расширить раздел Troubleshooting таблицей из 3–4 типичных проблем с конкретными командами решения (проверка версии `node -v`, очистка кэша `npm cache clean --force`).

### Комментарий 4: Добавление системных требований по аппаратному обеспечению
- **Категория:** Системные требования (`docs/install-guide.md`)
- **Суть замечания:**
  В системных требованиях указан только список поддерживаемых браузеров. Так как в приложении рендерится интерактивная масштабируемая карта парка (SVG/Canvas), на слабых устройствах возможны просадки частоты кадров.
- **Рекомендация:**
  Указать минимальные требования к оперативной памяти (от 2 ГБ RAM) и разрешению экрана (от 320px для мобильной адаптивности).
