## 4. Воспроизводимость результатов (Automated Test Stand)

В дополнение к ручному прогону по чек-листу, математические инварианты физического ядра подтверждены автоматизированным юнит-стендом:
- Команда запуска: `npm test` (или `npx tsx tests/physics.test.ts`)
- Проверено 5 наборов автоматических тестов:
  1. $v \le \text{SPEED\_OF\_LIGHT} = 60.0\text{ px/s}$ (PASS);
  2. $r = 0$, регуляризация $\text{denom} = 512.0$ (PASS);
  3. Сохранение линейного импульса $\vec{P}_{\text{after}} = \vec{P}_{\text{before}}$ с $\Delta P < 10^{-3}$ (PASS);
  4. Астрофизические константы $M_{\text{Chandra}} = 1.44\ M_\odot$, $M_{\text{TOV}} = 2.80\ M_\odot$ (PASS);
  5. 500 шагов орбитального интегратора Верле для системы Земля-Солнце ($\Delta r / r = 0.03\%$) (PASS).
