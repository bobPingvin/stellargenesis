### TC-03: Проверка стабильности орбиты Земли
- **Сценарий:** TS-02 (Гравитационное взаимодействие)
- **Приоритет:** Высокий
- **Предусловие:** Загружен пресет «Солнечная система», $G = 1.2$, $dt = 1.0$.
- **Шаги воспроизведения:**
  1. Зафиксировать начальные координаты Земли ($x_0 = 190.0, y_0 = 0.0, v_y = 2.52$).
  2. Запустить симуляцию непрерывно на 120 секунд реального времени (~7200 физических шагов).

- **Ожидаемый результат:** Расстояние колеблется в пределах $187.4 \le r \le 192.8$ пикселей. Эксцентриситет $e < 0.05$. Земля не падает на Солнце и не улетает за пределы видимости.

- **Статус:** ✅ PASS

### TC-04: Предотвращение деления на ноль при сближении тел ($\varepsilon = 8.0$)
- **Сценарий:** TS-02 (Гравитационное взаимодействие)
- **Приоритет:** Высокий
- **Предусловие:** Включен физический цикл, в расчет передаются две частицы.
- **Шаги воспроизведения:**
  1. Создать в коде два тела с координатами $(x_1=100, y_1=100)$ и $(x_2=100.0001, y_2=100.0001)$.
  2. Вызвать расчет сил гравитации: $distSq = dx^2 + dy^2 + \varepsilon^2$.
- **Ожидаемый результат:** Знаменатель не обращается в 0 благодаря сглаживанию $\varepsilon = 8.0$, результирующее ускорение $a = G \cdot m / (\varepsilon^2)^{1.5} < \infty$, значения координат не обращаются в `NaN`.
- **Фактический результат:** Знаменатель $distSq = 0.00000002 + 64.0 = 64.0$. Сила конечна ($F = 0.00234$), координаты после интегрирования: `x1=100.000, x2=100.000`. В консоли нет предупреждений `NaN` или `Infinity`.
- **Статус:** ✅ PASS
