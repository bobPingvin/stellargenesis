- **Фактический результат:** Расчет завершился штатно, значения координат валидны.
- **Статус:** ✅ PASS

### TC-15: Слияние двух массивных звезд с сохранением импульса
- **Сценарий:** TS-07 (Приливное разрушение и столкновения)
- **Приоритет:** Средний
- **Предусловие:** Две звезды движутся навстречу друг другу.
- **Шаги воспроизведения:**
  1. Дождаться физического контакта тел ($r < R_1 + R_2$).
  2. Зафиксировать параметры итогового тела.
- **Ожидаемый результат:** Тела объединяются в одно более крупное тело. Новая масса $M = M_1 + M_2$, новая скорость $\vec{V} = (M_1\vec{v}_1 + M_2\vec{v}_2) / (M_1 + M_2)$. Закон сохранения импульса соблюден.
- **Фактический результат:** Закон сохранения импульса выполняется строго, импульс сохранен.
- **Статус:** ✅ PASS
