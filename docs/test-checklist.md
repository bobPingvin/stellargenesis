## 1. Функциональность (Core Features & Astrophysics)
- [x] **Инициализация сцены:** Солнечная система отображается корректно (Солнце в центре, 8 планет с орбитальными линиями).
- [x] **Навигация:** Колесико мыши плавно меняет масштаб (Zoom In / Zoom Out), панорамирование зажатой ЛКМ перемещает камеру.
- [x] **Гравитационное взаимодействие:** Планеты обращаются по квазиэллиптическим кеплеровским орбитам без дрейфа в бесконечность.
- [x] **Предотвращение деления на ноль:** При сближении тел сглаживание $\varepsilon = 8.0$ исключает сингулярности в ускорениях.
- [x] **Спавн небесных тел:** Инструменты GodToolbar позволяют создавать звезды, планеты, пульсары и черные дыры с вектором начальной скорости.
- [x] **Инспектор объектов (StarInspector):** Одиночный клик открывает боковую карточку с точными астрофизическими величинами ($M, R, T_{\text{eff}}, L$).
- [x] **Изоляция 3D-режима:** Обычный клик по объекту НЕ вызывает переход в 3D (переход осуществляется строго по кнопке «3D Осмотр»).
- [x] **3D-осмотр (Three.js):** Отображает 3D-сферу планеты с текстурами или аккреционный диск черной дыры с релятивистским свечением.
- [x] **Термоядерная эволюция:** Кнопка взрыва Сверхновой корректно переводит массивную звезду в фазу пульсара или черной дыры со сбросом газовой оболочки.
- [x] **Предел Роша:** Приливное разрушение фрагментирует тестовые спутники, подошедшие ближе $d_{\text{Roche}}$, формируя кольца обломков.
- [x] **Неупругие столкновения:** При лобовом слиянии двух звезд выполняется закон сохранения импульса ($\vec{P} = \text{const}$).
- [x] **Управление временем:** Кнопка «Пауза» (`Space`) замораживает координаты; шаги времени $5\times, 50\times, 1000\times$ ускоряют процесс без числового взрыва.
- [x] **Каталог сценариев:** Пресеты («Солнечная система», «Танец трех тел», «Черная дыра», «Хаос») переключаются без утечки памяти.
- [x] **История действий:** Кнопка Undo (`Ctrl+Z`) отменяет удаление или спавн тел; Redo (`Ctrl+Y`) повторяет отмененное действие.
- [x] **Персистентность (LocalStorage):** Кнопка «Сохранить» (`Ctrl+S`) сохраняет конфигурацию; «Загрузить» восстанавливает тела после F5.

## 2. Нефункциональные требования (Performance, UX & Stability)
- [x] **Время старта:** Первоначальная инициализация симулятора занимает $< 1.5$ секунды.
- [x] **Стабильность кадров (FPS):** Частота кадров при $N \le 100$ удерживается на уровне $\ge 58$ FPS.
- [x] **Чистота консоли:** Отсутствуют неперехваченные исключения, предупреждения `NaN`/`undefined` и ошибки рендеринга.
- [x] **Мобильная адаптивность:** Интерфейс полностью функционален на экранах шириной от 320px (iPhone SE) без горизонтальной полосы прокрутки.
- [x] **Размер LocalStorage:** Сериализованный снимок системы занимает $< 50$ КБ (существенно ниже браузерной квоты в 5 МБ).
- [x] **Звуковое сопровождение:** Синтезатор Web Audio API воспроизводит космический гул и взрывы без щелчков и задержек потока.

## 3. Обработка ошибок и граничные условия
- [x] **Пустой космос ($N = 0$):** При очистке всех тел цикл физики не падает с ошибкой `Cannot read properties of undefined`.
- [x] **Сингулярность ($r = 0$):** При совпадении координат двух тел расчет не возвращает `NaN`, происходит слияние в одно тело.
- [x] **Экстремальная масса ($10^{12}\ M_\odot$):** Релятивистский лимитер $v \le \text{SPEED\_OF\_LIGHT} = 60.0\text{ px/s}$ блокирует разлет объектов.
- [x] **Экстремальный Time Warp ($1000\times$):** Внутренний механизм субшагов сохраняет устойчивость численного решения.
- [x] **Удаление активного объекта:** Удаление выбранного тела закрывает инспектор и сбрасывает режим слежения камеры без краша React.
- [x] **Исчерпание истории:** Многократное нажатие `Ctrl+Z` или `Ctrl+Y` при пустых стеках блокируется без ошибок.
- [x] **Стресс переключения пресетов:** 20 быстрых кликов по смене сценариев не вызывают состояния гонки (Race Condition).
- [x] **Сбой WebGL-контекста:** При недоступности 3D-ускорителя выводится предупреждение, приложение продолжает работу в 2D Canvas.
