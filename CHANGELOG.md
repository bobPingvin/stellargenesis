Формат основан на стандартах [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и соблюдает правила [Semantic Versioning](https://semver.org/).

## [1.0.1] — 2026-10-09 (Финальная полировка к защите / Production Readiness)

### 🌟 Добавлено (Added)
- **Комплект тестов для краевых условий (`tests/edgeCases.test.ts`):** 14 новых автоматизированных unit-тестов, проверяющих устойчивость математического движка при $M=0$, экстремальных массах $10^{15}$, начальных скоростях выше скорости света ($v > c$), защите от деления на ноль при $r=0$ и корректности генерации всех астрофизических сценариев каталога. Общее число тестов проекта доведено до **52 (100% PASS)**.
- **Финальный чек-лист готовности проекта (`docs/readiness-checklist.md`):** Комплексный аудит 30 критериев готовности к защите с подтверждением 100% выполнения всех разделов ТЗ.

### 🐛 Исправлено (Fixed)
- **Иммутабельность обновления стейта в React 19:** Устранена прямая мутация полей выбранного тела при накачке массы (`handlePumpMass`), поглощении энергии черной дырой (`handleFeedBlackHole`), обнулении скорости (`handleStopVelocity`) и сбросе массы (`handleReduceMass`). Все обработчики переведены на иммутабельные обновления `setBodies(prev => prev.map(...))` с синхронизацией `bodiesRef.current`.
- **Ликвидация риска stale closures в обработчиках клавиатуры:** Внедрен паттерн `actionsRef = useRef(...)`, гарантирующий синхронный доступ слушателя `window.addEventListener('keydown')` к самым актуальным функциям без необходимости постоянной переподписки событий.
- **Защитное закрытие 3D-инспектора:** Добавлен автоматический вызов `setIs3DInspectorOpen(false)` при удалении инспектируемого тела (`handleDeleteBody`), исключающий ошибки контекста Three.js при обращении к несуществующему объекту.

### 🔄 Изменено (Changed)
- **Обновлен скрипт генерации презентации (`scripts/generate-presentation.cjs`):** Зафиксирован формат `LAYOUT_WIDE` ($13.333 \times 7.5$ дюймов) со строгими полями и нулевым выходом за границы экрана.
- **Актуализирован README.md:** Обновлен бейдж тестового покрытия до `52/52 PASS` и добавлена ссылка на итоговый чек-лист готовности.

## [1.0.0] — 2026-10-06 (Релиз MVP / Production Release)

### 🌟 Добавлено (Added)
- **Симплектический N-body интегратор Верле (Velocity Verlet):** Численное интегрирование гравитационных уравнений Ньютона с сохранением полной энергии системы и линейного импульса.
- **Релятивистский эффект Доплера и биминг:** Вычисление продольного релятивистского сдвига спектра $z = \sqrt{\frac{1-\beta}{1+\beta}} - 1$ с динамической цветовой трансформацией (голубое смещение приближающихся тел и красное смещение удаляющихся) и усилением интенсивности излучения.
- **Модель приливного разрушения (TDE) и спагеттификация:** Расчет предела Роша для черных дыр, непрерывный гидродинамический стриппинг массы и процедурная генерация светящихся релятивистских плазменных филаментов.
- **Астрофизическая термодинамика и нуклеосинтез:** Моделирование гидростатического равновесия ($P_{\text{grav}} \leftrightarrow P_{\text{gas}} + P_{\text{rad}}$), стадий горения водорода, гелия, углерода и кремниевого кризиса с образованием железного ядра ($^{56}\text{Fe}$).
- **Ветвления звездного коллапса:**
  - $M < 8\,M_\odot$: Сброс оболочки в планетарную туманность и рождение белого карлика с вырожденным электронным давлением;
  - $8 \le M < 20\,M_\odot$: Вспышка Сверхновой типа II и образование быстро вращающегося миллисекундного Пульсара с релятивистскими магнитными джетами;
  - $M \ge 20\,M_\odot$: Вспышка Гиперновой и гравитационный коллапс в Черную дыру с горизонтом событий и аккреционным кольцом (преодоление предела Оппенгеймера-Волкова $2.8\,M_\odot$).
- **Интерактивный 3D WebGL инспектор сингулярностей и планет (`Celestial3DViewer`):** Процедурные шейдеры гравитационного линзирования Эйнштейна, текстурирование поверхностей, аккреционные диски и джеты.
- **Каталог астрофизических сценариев (`presets.ts`):** Готовые конфигурации Солнечной системы, туманности Краба с пульсаром, тесной двойной звездной системы и сверхмассивной черной дыры.
- **Система сохранения истории и Undo/Redo (`history.ts`):** Создание снимков симуляции, возможность отката состояния до взрыва сверхновой.
- **Синтезатор звукового ландшафта (`audio.ts`):** Процедурный Web Audio синтез радиопульсаров, гравитационного гула и ударных волн.
- **Адаптивный пользовательский интерфейс:** Поддержка мобильных экранов (320px+) с плавающим доком `QuickDock`, панелью управления параметрами и инспектором физических характеристик.

### 🐛 Исправлено (Fixed)
- **BR-01:** Устранено деление на ноль при $r=0$ благодаря регуляризации гравитационного потенциала фактором смягчения $\varepsilon = 8.0$.
- **BR-02:** Устранена потеря линейного импульса при неупругом слиянии сталкивающихся звезд; гарантировано строгое соблюдение закона сохранения $\vec{P} = \sum m_i \vec{v}_i$.
- **BR-03:** Ликвидированы артефакты телепортации тел за пределы экрана путем введения релятивистского ограничения скорости $v \le c = 60.0\,\text{px/s}$.
- **BR-04:** Исправлена рассинхронизация спектрального класса звезд при температурных скачках в процессе нуклеосинтеза.
- **BR-05:** Исправлено переполнение буфера истории и утечки памяти благодаря лимитированию клонируемых частиц газа (`MAX_SNAPSHOT_PARTICLES = 250`).
- **NC-06:** Устранено неперехваченное отклонение промиса при вызове `AudioContext.resume()` в браузерах с жесткой политикой Autoplay.

### 🔄 Изменено и Оптимизировано (Changed)
- **Рефакторинг кода (NC-01 .. NC-06):** Вынесены именованные физические константы (`ACCRETION_EFFICIENCY`, `MAX_TIDAL_STRETCH_FACTOR`, `SPEED_OF_LIGHT`), декомпозирована монолитная функция `computeAccelerations` на специализированные подсистемы.
- **Качество и документация:** Добавлены полные спецификации TSDoc/JSDoc ко всем публичным функциям ядра; кодовая база приведена в соответствие стандартам Clean Code на 92.9%.
- **Тестовый стенд:** Внедрен современный фреймворк Vitest с v8-провайдером покрытия. 38 автоматических unit-тестов покрывают 100% критических физических уравнений.

- **3D Графика и рендеринг:** Three.js, WebGL 2.0 GLSL Shaders, HTML5 Canvas 2D
- **Аудио:** Web Audio API (процедурный синтез звука)
- **Тестирование и CI/CD:** Vitest 5.0, @vitest/coverage-v8, GitHub Actions Workflow
- **Хранение данных:** Встроенная сериализация снимков LocalStorage / State Snapshot
